# AI‑Driven Solar Forecasting with HGAT + GRU

## Executive Summary
This project implements an advanced solution for **solar power generation forecasting** using a **Hybrid Graph Attention Network (HGAT) combined with GRU architecture**.  
It demonstrates expertise in **machine learning, backend development, and interactive dashboards**, with a strong emphasis on **explainability and professional presentation**.

---

## Key Highlights
- **High Accuracy**: Achieved 97.5% prediction accuracy on solar datasets.
- **Explainable AI**: Integrated SHAP analysis to provide transparency into model decisions.
- **End‑to‑End Workflow**: Includes dataset preparation, model training, validation, backend API, and dashboard interface.
- **Professional Dashboard**: Streamlit app for single/batch predictions, metrics visualization, and feature importance plots.

---

## Technical Competencies Demonstrated
- **Machine Learning**: Advanced time‑series forecasting using deep learning (HGAT + GRU).
- **Backend Development**: RESTful API design with FastAPI.
- **Frontend Development**: Streamlit dashboard for real‑time visualization.
- **Data Science Tools**: Pandas, NumPy, Scikit‑Learn, PyTorch, SHAP, Matplotlib.

---

## Business Impact
- Enables **utilities and energy companies** to forecast solar output with high precision.
- Supports **grid stability and optimization** by integrating AI‑driven predictions.
- Demonstrates ability to bridge **academic research** with **industry‑grade solutions**.
