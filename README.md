# Solar Forecasting Using HGAT + GRU

## Executive Summary
This project delivers an advanced solution for **solar power generation forecasting** using a **Hybrid Graph Attention Network (HGAT) combined with GRU architecture**.  
It demonstrates expertise in **machine learning, backend development, and full‑stack deployment**, with a strong emphasis on **explainability and professional presentation**.


## Key Highlights
- **High Accuracy**: Achieved 97.5% prediction accuracy on real‑world solar datasets.
- **Explainable AI**: Integrated SHAP analysis to provide transparency into model decisions.
- **End‑to‑End Deployment**: FastAPI backend and Streamlit dashboard deployed on cloud platforms.
- **Professional Dashboard**: Interactive interface for single/batch predictions, metrics visualization, and feature importance plots.


## Technical Competencies Demonstrated
- **Machine Learning**: Advanced time‑series forecasting using deep learning (HGAT + GRU).
- **Backend Development**: RESTful API design with FastAPI.
- **Frontend Development**: Streamlit dashboard for real‑time visualization.
- **Cloud Deployment**: Render and Streamlit Cloud integration for production‑ready hosting.
- **Data Science Tools**: Pandas, NumPy, Scikit‑Learn, PyTorch, SHAP, Matplotlib.


## Business Impact
- Enables **utilities and energy companies** to forecast solar output with high precision.
- Supports **grid stability and optimization** by integrating AI‑driven predictions.
- Demonstrates ability to bridge **academic research** with **industry‑grade solutions**.
